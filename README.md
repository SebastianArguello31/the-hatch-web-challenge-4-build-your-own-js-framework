# Mini JavaScript Framework

Proyecto educativo para construir un pequeño framework de JavaScript
desde cero y comprender cómo funciona internamente.

## Objetivo

Implementar componentes funcionales, creación de elementos virtuales,
renderizado del DOM, actualización de la interfaz y gestión de estado
mediante una arquitectura FLUX simplificada.

## Funcionalidades previstas

- Framework reutilizable desde un único archivo JavaScript.
- Componentes funcionales.
- Compatibilidad con JSX mediante una herramienta de transformación.
- Virtual DOM básico.
- Comparación y actualización de nodos.
- Manejo de eventos.
- Store con despacho de acciones y suscripciones.

## Tecnologías

- JavaScript y módulos ES.
- HTML y DOM API del navegador.
- JSX y Vite en las etapas posteriores.

No se utilizarán React, Vue, Angular ni bibliotecas de Virtual DOM
o gestión de estado.

## Instalación y ejecución

Esta etapa no requiere instalar dependencias.

Las instrucciones para ejecutar el ejemplo se incorporarán cuando
se implemente el renderizado y se configure el entorno de desarrollo.

## Aplicación de ejemplo

El framework se utilizará en una aplicación TODO independiente,
ubicada en el proyecto de CH4_Parte2.

## Alcance

El objetivo es demostrar los conceptos principales mediante código
sencillo y comprensible.

No se implementarán servidor, router, renderizado del lado del servidor,
hooks ni un sistema avanzado de reconciliación.
